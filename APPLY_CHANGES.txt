SINDIKAT STUDIO 83 - KOMPLETAN SADRZAJNI DRAFT

1. Raspakuj ZIP u root postojeceg Next.js repoa.
2. Dozvoli zamjenu postojecih fajlova.
3. Ne mijenjaj Netlify podesavanja:
   - Build command: npm run build
   - Publish directory: out
   - Base directory: prazno
4. Pokreni:
   Netlify -> Deploys -> Trigger deploy -> Clear cache and deploy site

Ovaj ZIP:
- sadrzi samo izmijenjene izvorne fajlove i dokumentaciju za pregled
- ne sadrzi node_modules, slike, build output ili Git istoriju
- ne mijenja GitHub direktno
- ne dodaje nepotvrdjene javne cijene
